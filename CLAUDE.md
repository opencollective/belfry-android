# Belfry for Android: notes for agents

Native Android client (Kotlin, Jetpack Compose) for a community's belfry. Work in progress: see
PARITY.md. The protocol contract is SPEC.md + vectors/ (copied from commonshub/belfry-ios at
commit ca5fea3); the web chat (village-app, branch belfry-chat) is the reference implementation.

Build on GitHub Actions only (no Android SDK on the dev box): push, then `gh run watch`.
